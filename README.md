# Student-Management-System
🎓 Student Management System (Django + REST API)
A full-stack Student Management System built using Python Django and Django REST Framework (DRF) to automate academic operations such as student management, attendance tracking, assignment handling, result processing, and communication workflows. The system provides secure role-based access for Admin, Teacher, and Student along with RESTful APIs for integration with web and future mobile applications.

🚀 Features
👨‍💼 Admin
Manage students, teachers, subjects, and classrooms

Monitor attendance, results, and assignments

Review feedback and leave requests

Full data control via Django Admin Panel

👨‍🏫 Teacher
Mark and update student attendance

Upload lectures and assignments

Add and update exam results

Interact with students through feedback

🎓 Student
View subjects, attendance, and academic results

Download lecture materials

Submit assignments online

Send feedback and request leave

View performance analytics dashboard

🛠️ Tech Stack
Backend: Python, Django

API: Django REST Framework (DRF)

Frontend: HTML, CSS, Bootstrap, JavaScript

Database: SQLite

Visualization: Chart.js

Architecture: MVT (Model–View–Template)
